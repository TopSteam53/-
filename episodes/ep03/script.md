# Эпизод 3 — «Топ-7 моментов вайбкодинга»

Формат: обратный отсчёт «топ-7» (номер пункта в углу держит досмотр до №1), ~49 с, голос тот же.
Не завязан на запись игры: все вставки — сгенерированные мем-кадры в TikTok-стиле. Барсика нет (по просьбе автора).
Это обобщённые, узнаваемые ситуации, а не выдуманные факты про автора.

## Хуки (выбран №1)

| # | Хук | Почему |
|---|---|---|
| 1 | «Если ты хоть раз делал что-то с нейросетью — ты узнаешь каждый пункт.» + «ЭТО ПРО ТЕБЯ 🫵» | **Выбран**: вовлекает зрителя лично, обещает узнавание — досматривают, чтобы «проверить себя» |
| 2 | «Нейросеть сказала: всё работает. Не работало ничего.» | Сильный панч, но тратит лучший пункт в первые секунды |
| 3 | «Топ-7 причин, почему вайбкодинг — это боль» | Понятно, но без личного крючка |

## Сценарий

| # | Текст | Кадр |
|---|---|---|
| хук | Если ты хоть раз делал что-то с нейросетью — ты узнаешь каждый пункт. | Крупный чат «✅ Готово! Всё работает!» + «Прошу прощения…» → 🫵 «ЭТО ПРО ТЕБЯ» |
| титр | Третья серия челленджа. Топ-7 моментов, когда делаешь игру с нейросетью. | Титр серии «ЭПИЗОД 3» → «ТОП-7 МОМЕНТОВ ВАЙБКОДИНГА» |
| #7 | Седьмое. Нейросеть пишет: «Готово, всё работает!» Не работает ничего. | Чат → консоль с ошибками «НИЧЕГО» → 💀 «ВСЁ РАБОТАЕТ ✅» |
| #6 | Шестое. Просишь поменять цвет одной кнопки… а она переписывает всю игру. | «сделай кнопку синей. ТОЛЬКО кнопку 🙏» → код переписывается, счётчик +1243 −1198 |
| #5 | Пятое. Исправила один баг — появилось три новых. [ПИ-И-ИП]. | Счётчик багов 1 → 3 → 7, цензурная плашка |
| #4 | Четвёртое. «Прошу прощения за путаницу». В пятнадцатый раз. | Стопка извинений ИИ + стикер «×15» |
| #3 | Третье. Заканчивается контекст — и она забывает, про кого игра. | «продолжаем игру про котиков» → «игру про собак 🐶» → 🐶 «ИГРА ПРО СОБАК» |
| #2 | Второе. Код вдруг заработал. Ты не знаешь почему. Трогать нельзя. | «✅ РАБОТАЕТ …а почему?» → код за лентой «НЕ ТРОГАТЬ» |
| #1 | И первое. Ты выкладываешь игру и ждёшь денег. И ждёшь. И ждёшь. | Загрузка билда → «₽ ?» → 💀 «ПРОШЛО 3 ГОДА ⏳» |
